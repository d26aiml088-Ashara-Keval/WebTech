How it works

Fetch, transform, render

fetch() loads a JSON array, response.json() parses it, and ES modules separate data loading, reusable rendering, and page behavior.

Array filter() powers search and category selection, sort() orders matching records, and slice() selects each page. The latest successful response is cached in localStorage for offline fallback.
